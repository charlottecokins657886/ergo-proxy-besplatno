### Как получить прокси

1. Откройте Ergo Proxy
2. Нажмите на вкладку **"Прокси"**
3. Выберите тип прокси (HTTP, HTTPS, SOCKS5)
4. Выберите страну (Россия, США, Германия и др.)
5. Нажмите **"Получить прокси"**
6. Скопируйте IP:порт

### Как настроить автоматическую смену IP

1. Нажмите на вкладку **"Ротация"**
2. Включите **"Автоматическая ротация"**
3. Выберите интервал (1, 5, 10, 30 минут)
4. Выберите режим (по времени / по трафику)
5. Нажмите **"Запустить ротацию"**

### Как настроить прокси в браузере

#### Для Google Chrome / Яндекс Браузер:
1. Настройки → Система → Открыть настройки прокси
2. Включить "Использовать прокси сервер"
3. Введите IP адрес и порт
4. Нажмите "Сохранить"

#### Для Mozilla Firefox:
1. Настройки → Основные → Настройки сети
2. Выбрать "Ручная настройка прокси"
3. Введите IP и порт
4. Нажмите "OK"

### Как настроить SOCKS5 для Telegram

1. Откройте Telegram Desktop
2. Настройки → Продвинутые → Тип подключения
3. Выберите "Подключаться через прокси SOCKS5"
4. Введите IP адрес, порт
5. Нажмите "Сохранить и подключиться"

### Как настроить прокси для Steam / Discord

1. Откройте Ergo Proxy
2. Нажмите **"Игровой режим"**
3. Выберите приложение (Steam, Discord, Epic)
4. Нажмите **"Применить прокси"**
5. Запустите приложение
